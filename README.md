# 🎓 EduSales AI

## Copiloto de Vendas com IA para Atendimento ao Cliente

O EduSales AI é uma solução de Inteligência Artificial desenvolvida para apoiar equipes comerciais na venda de cursos e serviços educacionais.

A ferramenta funciona como um copiloto para vendedores e atendentes, ajudando a compreender as necessidades dos potenciais alunos, sugerir respostas, lidar com objeções e indicar os próximos passos do atendimento.

## 🎯 Objetivo

Utilizar Inteligência Artificial para tornar o atendimento comercial mais personalizado, consultivo e eficiente, sem substituir o trabalho do vendedor.

## 👥 Público-alvo

Vendedores, atendentes e equipes comerciais de instituições de ensino e empresas que comercializam cursos.

## 🤖 Principais funcionalidades

- Identificação do perfil e das necessidades do potencial aluno;
- Sugestão de respostas para mensagens de clientes;
- Tratamento de objeções;
- Recomendação de cursos;
- Sugestão do próximo passo da negociação;
- Organização das informações do atendimento.

## 📚 Base de conhecimento

O projeto utiliza uma base de conhecimento fictícia da instituição educacional Educa+, contendo informações sobre cursos, perguntas frequentes, objeções comerciais e contexto do negócio.
